# tm__hud

Ультра-минималистичный прозрачный HUD-оверлей для Windows поверх всех окон, отображающий загрузку CPU, RAM и GPU (NVIDIA, AMD, Intel) в реальном времени.

## Особенности
* **Минимализм и прозрачность:** отображается только текст без рамок и фона, не мешает в играх и при работе.
* **Универсальный мониторинг:** показывает загрузку процессора (CPU), объём занятой оперативной памяти (RAM), а также загрузку и температуру видеокарты (для NVIDIA — загрузка и температура, для AMD и Intel — загрузка 3D-движка GPU).
* **Низкое потребление ресурсов:** интерфейс перерисовывается только при фактическом изменении показателей.
* **Управление из системного трея:**
  * Выбор из 12 предустановленных цветов текста (иконка в трее динамически меняет цвет под выбранный пресет).
  * **Режим перемещения:** включает подложку для удобного перетаскивания виджета мышью в любое место экрана с автоматическим сохранением координат в `config.json`.
  * Сброс позиции в стандартный угол экрана.
* **Защита от дублирования:** приложение использует локальный сокет и не позволяет запустить вторую копию процесса.

## Установка и запуск из исходников

1. Убедитесь, что установлен **Python 3.10+**.
2. Установите необходимые зависимости:
   ```bash
   pip install customtkinter psutil pynvml pillow pystray
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```

## Сборка в исполняемый файл (.exe)

Для упаковки проекта в единый автономный `.exe` файл без консольного окна используйте **PyInstaller**:

```bash
pyinstaller --clean --noconsole --onefile --name "tm__hud" --icon="app.ico" --add-data "app.ico;." main.py
```

Готовый файл появится в папке `dist/tm__hud.exe`. Рядом с ним при первом запуске автоматически создастся файл настроек `config.json`.
